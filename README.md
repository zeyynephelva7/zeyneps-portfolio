# Zeynep's Portfolio 2

A four-page personal portfolio draft built with HTML, CSS, and JavaScript.

## Flow

- Cover page with an opening animation
- About Me page with a camera photo interaction
- Stage page with light and outfit mode controls
- Blank white fourth page reserved for future content

The page flow is interaction-based: open the cover to reach About Me, press the camera button to move to the stage, then continue scrolling to the blank fourth page.
